Notation Equations Code & references

Notation

Inline notation, such as a random variable \(X \in \mathbb{R}\), belongs in the flow of the text. Use \( ... \) for inline maths and \[ ... \] for an unnumbered display. Ordinary amounts like $20 remain ordinary text.

Equations

Here is a numbered equation with a label:

\begin{equation} p(x \mid \mu, \sigma) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right), \qquad \sigma > 0. \label{eq:normal} \end{equation}

Equation \(\eqref{eq:normal}\) can be referenced from elsewhere in the article. Multi-line derivations use the usual align environment:

\begin{align} \mathbb{E}[X] &= \mu, \\ \operatorname{Var}(X) &= \sigma^2. \end{align}

Code & references

Code stays as code, including LaTeX delimiters. Wide blocks scroll within the article.

import numpy as np

def normal_density(x, mu, sigma):
    if sigma <= 0:
        raise ValueError("sigma must be positive")
    return np.exp(-0.5 * ((x - mu) / sigma) ** 2) / (sigma * np.sqrt(2 * np.pi))

State the question, give the necessary context, and distinguish an observation from an interpretation.

Use semantic figure and figcaption elements for figures. Write meaningful alternative text and keep captions near the material they explain.
